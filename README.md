# Personal Budget Tracker

## Project Overview

Personal Budget Tracker is a web application developed using Java, Spring Boot, Thymeleaf, MySQL, Bootstrap, and Chart.js. It helps users manage their income and expenses while providing dashboard insights and visual reports.

## Features

* Add Income and Expense Transactions
* Edit Existing Transactions
* Delete Transactions
* Transaction History Management
* Dashboard with Income, Expense, and Balance Summary
* Monthly Income and Expense Tracking
* Visual Reports using Charts
* MySQL Database Integration

## Technologies Used

* Java 17
* Spring Boot
* Spring Data JPA (Hibernate)
* Thymeleaf
* MySQL
* Bootstrap 5
* Chart.js
* Maven

## How to Run

1. Clone the repository.
2. Configure MySQL database.
3. Update `application.properties` with database credentials.
4. Run `BudgetTrackerApplication.java`.
5. Open the application in a browser.
